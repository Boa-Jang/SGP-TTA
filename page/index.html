SGP-TTA: Skeleton-Guided Progressive

SGP-TTA wraps a trained segmentation network with Progressive BN and a skeleton-guided objective, adapting per image without labels.

Abstract

Tubular structures — retinal vessels, OCTA microvasculature, roads in aerial imagery — share a thin, elongated topology that collapses under distribution shift. We present SGP-TTA, a single-image test-time adaptation wrapper for segmentation networks that preserves this topology without any target labels and without touching the training pipeline. Our method combines Progressive Batch Normalization (ProgBN), a square-root schedule that blends source running statistics with target-batch statistics as more target images arrive, with a Skeleton-Guided objective that anchors multi-view consensus predictions to their shared skeletal centerline. Only the BN affine parameters are updated. Across retinal-vessel, OCTA, and aerial-road benchmarks, SGP-TTA improves Dice and clDice over strong TTA baselines while keeping thin branches intact.

Method

1. Progressive Batch Normalization (ProgBN)

Every nn.BatchNorm2d in the source model is replaced by a layer that blends the frozen source running statistics with the current-batch target statistics using a monotonic square-root warmup over the target-sample counter n:

$$\alpha_n \;=\; \frac{\sqrt{n}}{\sqrt{n} + \tau}, \qquad \mu \;=\; \alpha_n\,\mu_{\text{tgt}} + (1-\alpha_n)\,\mu_{\text{src}}$$

Small τ warms up quickly; large τ stays anchored to source statistics for longer. The running buffers themselves are never written to.

2. Skeleton-Guided Objective

For each incoming image we form six augmented views (identity, two flips, three 90° rotations), average their per-view predictions into a Multi-View Consensus map, and update only the BN affine parameters with two losses:

  • Consensus entropy on the mean prediction.
  • Consensus Skeleton Recall (CSR): skeletonize the binarized consensus, dilate it into a thin tube, and penalize 1 − recall of each view's probability against that tube.

CSR anchors the network to the structural centerline, so thin branches survive the entropy pressure toward confident predictions.
